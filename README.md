# Mini Shop Management System

A beginner-friendly shop management system developed using Python to practice programming concepts, data structures, functions, and basic file handling concepts.

## 🛒 Project Overview

This project simulates a simple shop management system where users can manage products, search for products, process sales, monitor low-stock items, and view sales summaries.

## 🛠️ Technologies & Concepts

* Python
* Data Structures
* Dictionaries
* Lists
* Tuples
* Sets
* Functions
* Loops
* Conditional Statements
* User Input & Validation

## ✨ Features

* Add Product
* View Products
* Search Product
* Sell Product
* Low Stock Report
* Sales Summary
* Exit

## 📦 Product Management

The system stores product information such as:

* Product ID
* Product Name
* Price
* Quantity
* Category

## 💰 Sales Management

The system allows users to sell products while checking available stock and calculating the total sale amount.
